# 财赋思应用脚本使用说明

本文档说明了项目目录中的脚本文件及其用途。

## 主要脚本文件

### 1. `setup.cmd` - 安装程序

用于初始化项目，安装前端和后端所需依赖。第一次使用项目时需要运行此脚本。

使用方法：双击运行，等待安装完成。

### 2. `start.cmd` - 一键启动应用

启动完整应用（包括前端和后端服务）。这是使用本应用的主要启动方式。

使用方法：双击运行，等待前端和后端服务启动。服务启动后，可以通过浏览器访问：
- 前端页面：http://localhost:3000
- 后端API：http://localhost:5001

### 3. `start-frontend.cmd` - 仅启动前端

仅启动前端服务，用于前端开发或者后端已经在运行的情况。

使用方法：双击运行，等待前端服务启动。

### 4. `start-backend.cmd` - 仅启动后端

仅启动后端服务，用于后端开发或者前端已经在运行的情况。

使用方法：双击运行，等待后端服务启动。

## 注意事项

1. 运行任何脚本前，请确保已安装Node.js、npm和Python。
2. 关闭启动窗口不会停止服务，需要手动关闭服务窗口来停止服务。
3. 如有问题，请查看各个服务窗口中的日志信息。
