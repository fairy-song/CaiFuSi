# Sunny-Ngrok内网穿透使用说明

## 简介

Sunny-Ngrok是中国本地化的内网穿透工具，基于ngrok开发，提供更稳定、更快速的国内服务器节点。通过Sunny-Ngrok，您可以：
- 将本地Web服务发布到公网
- 远程访问内网资源
- 进行移动端调试测试
- 实现WebHook接收和处理

## 使用步骤

### 1. 注册账号

1. 访问 [Sunny-Ngrok官网](https://www.ngrok.cc/)
2. 点击"登录"，然后选择"注册"
3. 填写注册信息并完成注册

### 2. 创建隧道

1. 登录 [用户中心](https://www.ngrok.cc/user.html)
2. 点击"隧道管理"
3. 点击"开通隧道"
4. 选择隧道协议（HTTP/HTTPS/TCP）
5. 填写隧道信息：
   - 隧道名称：自定义名称
   - 隧道协议：HTTP或HTTPS
   - 本地端口：填写您的本地端口（前端通常是3000，后端通常是5001）
   - 服务器地区：选择离您最近的服务器
   - 自定义域名：付费版可以设置自定义子域名

### 3. 下载客户端

1. 访问 [下载页面](https://www.ngrok.cc/download.html)
2. 下载Windows版本的Sunny-Ngrok客户端
3. 解压文件到合适的目录，例如 `E:\国创赛\caifusi_project\sunnyNgrok`

### 4. 启动内网穿透

有两种方式可以启动Sunny-Ngrok：

#### 方式一：使用我们提供的脚本

1. 运行 `start-sunny-ngrok.cmd`
2. 按提示输入您的隧道ID
3. 等待服务启动

#### 方式二：手动启动

1. 打开命令提示符
2. 进入Sunny-Ngrok所在目录
3. 执行命令：`sunny.exe clientid 您的隧道ID`
4. 如果需要同时启动多个隧道，可以使用：`sunny.exe clientid 隧道ID1,隧道ID2`

### 5. 使用公网URL

启动成功后，Sunny-Ngrok客户端会显示分配的公网URL，格式如：
- `http://xxx.ngrok.cc` 或 `http://xxx.ngrok.xiaomiqiu.cn`
- 自定义域名（如果您设置了）

## 注意事项

1. **免费版限制**：
   - 单次最长使用8小时
   - 每个账户可以创建2个隧道
   - 限制并发连接数

2. **付费版特性**：
   - 自定义子域名
   - 更多并发连接数
   - 更长的会话时间
   - 更多隧道数量

3. **端口配置**：
   - 创建隧道时需要指定本地端口
   - 确保填写的端口与本地服务端口一致
   - 不同隧道需要不同的端口

4. **服务器选择**：
   - 选择离您最近的服务器以获得最佳速度
   - 不同地区的服务器可能有不同的网络环境

## 常见问题

1. **连接被重置**：可能是因为服务器负载过高或网络不稳定，尝试换一个服务器节点

2. **隧道启动失败**：检查您的隧道ID是否正确，以及本地服务是否已启动

3. **客户端闪退**：尝试以管理员身份运行客户端

4. **域名无法访问**：检查防火墙设置，确保本地服务正常运行
