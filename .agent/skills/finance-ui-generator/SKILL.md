# 金融 UI 组件与数据展示规范

在生成、修改前端 UI 组件（如数据表格、资产卡片、对话气泡等）并且涉及用户资产、交易记录或 AI 财务分析结果展示时，必须严格遵守以下财务视觉格式和数据脱敏规则：

## 核心规则

1. **金额标准化格式**
   - **必须**包含正确的货币符号（如 `¥`, `$`, `€` 等）。
   - **强制**添加千分位逗号分隔符，且保留正确的小数位数（通常为两位小数，如 `¥1,234,567.89`）。
   - 不能直接展示未经任何格式化的原始数字串给用户。

2. **敏感信息默认脱敏**
   - 在生成 UI Mock 数据或编写组件的展示层逻辑时，凡涉及用户敏感信息的，**必须**默认提供脱敏处理的占位符或脱敏展示逻辑。
   - **银行卡号：** 仅展示后四位，其余使用星号遮挡（例如：`**** **** **** 1234` 或 `尾号 1234`）。
   - **手机号码：** 隐藏中间四位（例如：`138 **** 5678`）。
   - **真实姓名：** 隐藏名字的部分字符（例如：`张*明`、`*三`）。

3. **涨跌幅（正负数）的色彩与符号标识**
   - 当展示收益率、涨跌幅或当日盈亏等正负浮动数据时，**必须**带有明确的正负号（即正数前加 `+`，负数前加 `-`）。
   - **必须**通过颜色区分正负：
     - 正数强制使用红色或绿色（请根据当前项目设定的大盘/市场习惯，如 A股“红涨绿跌” 或 美股“绿涨红跌”）。
     - 负数使用对应的反色展示。
     - 若涨跌幅为 `0` 或 `0.00%`，建议使用中性色（如灰色）且不加 `+` `-` 符号。

当你的任务涉及前端涉金融组件的生成或修改时，请自动应用上述规则确保 UI 的专业度、安全性与合规性。
