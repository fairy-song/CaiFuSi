# 财赋思 (Caifusi) - AI金融心智教练

## 项目介绍
财赋思是一款基于人工智能的金融心智教练应用，旨在帮助用户培养健康的财务心态，提升金融决策能力，并实现个人财务目标。

## 主要功能
- 个性化金融心智指导
- 金融知识学习与咨询
- 财务目标设定与跟踪
- 心理压力管理与情绪引导
- 交互式学习体验

## 技术栈
- 前端：React、Bootstrap
- 后端：Python、FastAPI
- AI模型：智谱AI的GLM-Z1-air模型
- 数据存储：SQLite、JSON
